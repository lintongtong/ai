示範資料
目前是示範資料80 檔隨機產生的虛構個股（代號 D 開頭），只用來試操作。資料排程第一次跑完後，這裡會自動換成全市場真實資料。

取得真實資料

  1. GitHub 自動更新：repo 的 Actions 排程「台股資料更新」每個交易日 17:10 後自動抓資料；從 GitHub Pages 開這個網頁會自動讀最新一份。
  2. 在自己電腦跑：執行 python fetch_tw_stocks.py（Python 3.9 以上，免裝套件），產出 stocks.json 後按上方「載入資料檔」。

資料來源：臺灣證券交易所、證券櫃檯買賣中心、公開資訊觀測站。EPS 以「收盤價 ÷ 本益比」推算（近四季），ROE 以「股價淨值比 ÷ 本益比」推算，皆為估算值。
