資料怎麼來

  1. GitHub 自動更新：Actions 排程「台股資料更新」每個交易日 17:10 後自動抓資料；從 GitHub Pages 開這個網頁會自動讀最新一份。
  2. 自己電腦跑：執行 python fetch_tw_stocks.py（Python 3.9 以上），產出 stocks.json 後按「載入資料檔」。

來源：臺灣證券交易所、證券櫃檯買賣中心、公開資訊觀測站。EPS＝收盤價 ÷ 本益比、ROE＝股價淨值比 ÷ 本益比，皆為推算值。紅色代表上漲、綠色代表下跌。
