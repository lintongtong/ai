# 台股選股工作台

用條件組合篩選台股上市櫃普通股，四個面向可自由搭配：

| 面向 | 可用條件 |
|---|---|
| 基本面 | 月營收年增率連續 N 月成長、最新月營收年增、近 3 月平均年增、營收創 N 月新高、EPS（近四季）、ROE |
| 技術面 | 站上週線／月線／季線／半年線／年線、均線多頭排列、創 N 日新高、N 日漲幅區間、爆量、均量門檻、股價區間 |
| 籌碼面 | 外資／投信近 N 日累計買超、外資連續買超、土洋同買 |
| 評價面 | 本益比區間、殖利率、股價淨值比 |

另外有：策略儲存、個股詳情（股價與均線、月營收年增、法人買賣超）、觀察清單、簡易回測（定期換股、扣交易成本、對比 0050）、匯出 CSV。

## 網址

`https://lintongtong.github.io/ai/tw-stock/`

網頁只讀真實資料；排程第一次跑完前會顯示「資料準備中」。

## 資料怎麼更新

- `.github/workflows/tw-stock-data.yml`（Actions 名稱「台股資料更新」）每個交易日台北時間約 17:10 自動執行。
- 產出的 `stocks.json` 放在 **stock-data 分支**，每次覆蓋，不會讓 main 的歷史越來越大。
- 第一次要抓一年份資料，約 40～60 分鐘；之後每天只補新的一天，幾分鐘就完成。
- 手動執行：GitHub → Actions →「台股資料更新」→ Run workflow（可先填 60 天快速試跑）。
- 修改 `fetch_tw_stocks.py` 或排程設定並推上 main 時，也會自動執行一次。

## 資料來源

| 資料 | 來源 |
|---|---|
| 每日收盤價、成交量 | 臺灣證券交易所 MI_INDEX、櫃買中心 dailyQuotes |
| 外資、投信買賣超 | 證交所 T86、櫃買中心三大法人 |
| 本益比、殖利率、股價淨值比 | 證交所 BWIBBU_d、櫃買中心 peQryDate（每月一次＋最新一天） |
| 月營收 | 公開資訊觀測站 t21sc03 彙總表 |

EPS 以「收盤價 ÷ 本益比」推算，ROE 以「股價淨值比 ÷ 本益比」推算，都是估算值。

## 在自己電腦跑（備用）

如果 GitHub 的主機被證交所擋住，可以改在自己電腦執行：

```
cd tw-stock
python fetch_tw_stocks.py          # Python 3.9 以上，免裝套件
```

產出 `stocks.json` 後，在網頁按「載入資料檔」選取即可。

## 注意

本工具僅協助縮小研究範圍，篩選與回測結果不構成投資建議。
